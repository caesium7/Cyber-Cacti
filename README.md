# Cyber Cacti

Cyber Cacti is an app combining environmental awareness, robotics and hedgehog conservation.

## Features

- User accounts and login
- Hedgehog information
- Wildlife conservation checklist
- FLL Innovation Project
- Hedgehog Dash game

## Platforms

- Windows 11

## Updates

New versions will be published through GitHub Releases.

## How to download

Click on the latest release, from the Releases tab on the right. From there, scroll down to Assets and double-click the .exe file in order to download it.
